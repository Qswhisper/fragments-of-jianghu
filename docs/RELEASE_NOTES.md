# 1.0.43

江湖残卷 1.0.43，支持 Windows、Android 与 PC 浏览器离线游玩。

## 本次更新

- 完善卷间剧情、人物联系及事件后续，明确终章后的本局结算入口。
- 精简卡牌说明，改善悬停细读与手机阅读排版。
- 优化下三滥起手，调整撒石灰与断筋。
- 提供自带运行环境的 Windows 完整离线安装包。
