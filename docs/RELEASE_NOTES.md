# 江湖残卷 · 1.0 正式版

这是首个正式公开版本，以当前完整旅程为发布基线。

- 四种流派、五卷路线、卡牌构筑与宿敌系统。
- 暗色武侠场景、移动端卡牌用途标识、连续出牌与对应动作反馈。
- PC 离线版与 Android 安装包，使用本机存档。

下载 `Fragments-of-Jianghu-1.0-Android.apk` 或 `Fragments-of-Jianghu-1.0-PC.zip`；SHA256 见同一 Release 的 `SHA256SUMS.txt`。

PC 解压完整目录后打开 `play.html`。Android 8 及以上，横屏；官方同签名覆盖升级可保留进度。游戏免费离线运行。

本仓库的 Source code ZIP/TAR 是程序源码；直接游玩请选择上述完整游戏包。开发者按 README 的资源准备步骤运行源码。

本次源码发布不改变已交付游戏的规则、媒体或存档。个别设备可能仍有兼容问题；请通过 Issue 提交设备、场景及重现步骤。
